LLM Boundary Map

Today one Sonnet call does almost everything between fetching the records and the human review. Most of that work is lookups and arithmetic on database fields, which code does exactly, instantly and for free. This page shows each step, who does it now, and who should.

What it would save

Cost per case

Measured · V0
$0.023

Average of 162 cases on Sonnet 5.5: about 5,900 input tokens (57% from cache) and 1,750 output tokens. Output is about $0.017 of the total.

Estimate · proposed
≈ $0.01

A Haiku reading call costs well under a tenth of a cent. A Sonnet letter for the roughly 78% of cases that are fight or escalate is about a cent. Accept cases cost almost nothing. Measure before relying on it.

Estimate · speed
0 s

LLM time for an accepted case, down from 10.6 s typical today. Fight and escalate cases still wait for the letter, and can be written in the background while the reviewer reads the summary.

At roughly 2 cents a case, model cost is small next to the $35 it costs to fight a dispute. The stronger reasons to move work to code are accuracy and being able to explain every decision.

A catch to plan for: the eval would grade the code against itself

The correct answers are produced by the same rules (decision.toml and the rules table) that the proposed decision code would run. Moved to code, the decision layer would score 100% by construction, and that score proves nothing about real disputes.

The meaningful test moves to what the model still does: reading text. That needs labels written by a person for the text-based items (customer acknowledged receipt, remedy offered, messages that contradict tracking, which way Mastercard 4853 goes), and test messages written to be messy rather than generated from templates. Hand-labelling those is the most useful work for a PM in this design.

Suggested order

How to roll it out and measure it

  1. Decision layer to code

    Rules table, field checks, P(win), EV and the 7 rules. The model still reads text and writes the letter. This should remove most of V0's 20 wrongly escalated and 13 wrongly accepted cases. Compare on the same 162 cases.

  2. Letters only for fight and escalate

    Accepted cases get a template. Smaller bill, and the judge has fewer letters to grade.

  3. Haiku for reading text

    Run it next to Sonnet on the text-based items and keep it only if accuracy holds on your hand-written labels.

  4. Cheaper judging

    Batch API and judging only changed letters right away. Switch the judge model only after the 40-letter calibration.

Measured figures come from evals/results/v0 (162 cases, 9 November 2026). Estimates use Anthropic list prices: Haiku 5.5 $0.10 / $0.50, Sonnet 5.5 $2 / $10, Opus 5.5 $4 / $20 per million input / output tokens; Batch API is half price. All data is synthetic.
